# Farol Studio

Canal público oficial de distribuição para macOS, Windows e Linux. O código-fonte é mantido em repositório privado.

Baixe os instaladores na [release mais recente](https://github.com/aeresdigital/aeres_farol_releases/releases/latest).

O Studio consulta este canal sem conta ou token GitHub. Cada release traz instaladores, checksums SHA-256 e metadados de build. No macOS, a build atual tem assinatura ad hoc, sem notarização; Windows e Linux não possuem assinatura de distribuição.

Os arquivos de código-fonte automaticamente oferecidos pelo GitHub contêm somente a documentação deste canal, e não o código do produto.
